# Kajal Didi — Ultimate Birthday Experience 💗

A premium, responsive, 10-page birthday presentation made for Kajal Didi. Every screen has its own layout and message. Visitors move forward only by tapping the button.

## ✨ Features
- 10 unique presentation pages — welcome, personal letter, long Hindi shayari, wishes, photo frame, memory wall, fun award, interactive birthday cake, brother's promise and finale.
- Continuous gentle emoji rain on every page (flowers, hearts, butterflies, sparkles and more).
- Pink, purple, black and champagne-gold premium theme.
- Stylish typography, glass cards, paper-letter design and animated transitions.
- Interactive candle wish and finale confetti.
- Optional soft synthesized chime. It starts only after the visitor taps SOUND.
- Responsive on phones, tablets and desktop.
- No framework, no build step, no API key.

## 🖼️ Add Kajal Didi's photo
1. Open the `assets` folder.
2. Put your sister's photo inside it.
3. Rename the image exactly to `kajal.jpg` (JPG format).
4. The page already has a decorative portrait frame and will load `assets/kajal.jpg`.

If you prefer a PNG, either convert it to JPG and name it `kajal.jpg`, or change the image path in `index.html` from `assets/kajal.jpg` to your filename.

## 🚀 Publish on GitHub Pages
1. Create a new GitHub repository, for example `kajal-birthday`.
2. Extract this ZIP on your device.
3. Upload the contents of the extracted folder to the repository root — upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder. Do not upload only the ZIP.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for deployment. Your website URL will look like:
   `https://YOUR-USERNAME.github.io/kajal-birthday/`

## Notes
- Keep all files in the same structure when uploading to GitHub.
- The website does not automatically upload your local photo; you must add `assets/kajal.jpg` to the GitHub repository for visitors to see it.
- Sound is optional and user-activated; the site does not autoplay audio.
